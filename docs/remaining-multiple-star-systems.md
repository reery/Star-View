# Remaining multiple-star systems review

Reviewed 2026-10-05 after the five approved associations were added. This is a source audit, with no runtime changes, tests, build, lint, or browser checks.

The complete ID-level findings and input fingerprints are in [remaining-review.json](../catalog-work/star-systems/remaining-review.json). The earlier [baseline audit](multiple-star-catalog-audit.md) predates the five additions.

This is a **historical snapshot before the broader implementation**. The 67
association candidates below have since been implemented, and reviewed companion
records and several held hierarchies have been added. See the
[current 25 pc expansion](companion-expansion-25pc.md) for current counts and the
remaining source-review queue. The original tables are retained as review history.

## Literature checks and naming corrections

- **GJ 229:** the bundled B record predates the resolved Ba/Bb discovery. [2024 discovery paper](https://arxiv.org/abs/2410.11953).
- **GJ 570:** the brown dwarf is D, despite the CNS5 B label. Published work describes the host ABC system. The current runtime has A and D, so B/C require separate reviewed records. [Discovery paper](https://arxiv.org/abs/astro-ph/0001194).
- **GJ 1001:** the L 362-29 BC record is a resolved brown-dwarf binary in the literature, while the bundled row has a combined L5+L5 spectrum. [Discovery proceedings](https://static.cambridge.org/content/id/urn%3Acambridge.org%3Aid%3Aarticle%3AS1743921307004255/resource/name/golimowski.pdf).
- **GJ 105:** associating existing A/B rows is supported, but C is absent from runtime. A 2025 orbital analysis gives individually measured AC masses; sourcing a C row is separate work. [Orbit and dynamical masses](https://arxiv.org/abs/2505.08042).
- **GJ 867:** FK Aqr itself is a double-lined spectroscopic binary, so treating the two catalog rows as only two physical stars would need care. [FK Aqr study](https://arxiv.org/abs/2312.04247).
- **COCONUTS-2b:** a planetary-mass companion; defer presentation to the planned full star/planet System section. [Discovery paper](https://arxiv.org/abs/2107.02805).
- **Fomalhaut:** A/B can be explicitly associated despite reciprocal CNS5 primary pointers. C (LP 876-10, CNS5 5623) exists in the frozen source but was excluded because its frozen SIMBAD type is `**`. Published work supports the wide A/B/C association and does not confirm the claimed close companion to C. Review C individually before admitting it; the source type alone does not establish an aggregate. [Fomalhaut C study](https://arxiv.org/abs/1310.0764).

## Proposed order of work

1. Review display names and adopt the 67 associations using existing stable IDs, preserving aliases and component-specific selection. Use cataloged-member counts without claiming complete physical membership.
2. Fomalhaut A/B/C is implemented with an explicit source-backed association and a reviewed C record.
3. Resolve the 17 held groups with hierarchical or combined labels and individual component data where available.
4. Review the 47 isolated records and the aggregate exclusion policy individually. Keep unsupported specifications nullable and preserve the frozen membership cutoff until a catalog change is explicitly chosen.
