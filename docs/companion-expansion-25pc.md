# Companion expansion within 25 pc

Reviewed 2026-10-06. The original 37-record follow-up queue has now been researched in [the component research report](component-research-37.md); its proposals are not yet applied. This pass covers companions of systems represented in the three base catalogs, using the approved 25 pc vicinity. It searches all 5,909 corrected CNS5 source rows for explicit system partners, the available frozen SIMBAD records, the frozen 10pc candidate subset and primary literature. It is not a complete census of every star within 25 pc.

The nearest-1000 package retains all 1,000 original non-Sun entries and adds **36 reviewed individual components**, for **1,036 non-Sun objects plus Sun**. The smaller two catalog memberships remain their original snapshots. Source-backed associations are shared wherever their member IDs occur.

Every confirmed stellar B-related record in this audit is associated. The remaining record, COCONUTS-2b, is a planetary-mass companion whose full system presentation is deferred to the planned star-and-planet System section. It remains in the frozen catalog. See its [discovery paper](https://arxiv.org/abs/2107.02805).

Only one unrepresented CNS5 partner of a system present in nearest-1000 remains within the vicinity: **RX J1214.1-2345 B (CNS5 3006)**, whose frozen classification is tentative `BD?`. It has not been promoted to a confirmed object. Nearest-100 also lacks the original GJ 229 B source row at its own cutoff; the larger package now represents the confirmed Ba/Bb components.

## Measurements and positions

- Adopt component-specific published measurements with their reference, uncertainty and measured, dynamical, estimated or model-derived status. Convert Jupiter masses/radii to the runtime solar units while retaining original units and values in provenance.
- Withhold combined photometry, masses, temperatures and other blended estimates when splitting a source record. Deliberately withheld fields cannot be restored from an overlapping legacy overlay.
- Prefer independent source astrometry when available. Newly separated close companions otherwise share the source system J2000 position and proper motion as an explicitly documented approximation. No invented separation, orbital phase or individual radial velocity is supplied.
- Decorative card pictograms depict available components, not measured orbital geometry. Shared-position companions can coincide in the scene and remain individually selectable in the Object Browser and card.
- Keep uncertain identity, classification and measurement fields blank. A source `SB*`, `**` or component-count flag does not by itself establish a new classified stellar record.

## Reproduction and review state

- Source decisions: [individual-object-overrides.json](../catalog-work/nearest-1000/individual-object-overrides.json) and [reviewed-companions.json](../catalog-work/nearest-1000/reviewed-companions.json). Their SHA-256 fingerprints are included in generated provenance.
- Catalog authoring: `scripts/author-nearest1000.py build --output <new-directory>` using the existing catalog Python environment. This writes the reviewed package; do not use `--check` before validation is authorized.
- Coverage-report authoring: `python3 scripts/audit-star-systems.py` reads sources and writes the report with input fingerprints.
- Browser payload generation: `node scripts/catalogs.ts generate`.
- Catalog files and browser payloads were regenerated. **No tests, application build, lint, typecheck or browser checks were run.** Runtime behavior awaits user inspection.
