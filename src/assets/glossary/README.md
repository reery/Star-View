# Glossary schematics

Original Star View SVG drawings for the object-subtype glossary. They show
mechanisms, rather than specific catalog objects or measured data. Distances,
sizes, colors, line strengths and brightness curves are illustrative. The
glossary captions identify them as schematics, and the images have text
alternatives. Images use `contain` so labels and diagrams are not cropped.

| Asset | Purpose |
| --- | --- |
| `stellar-fusion.svg` | Hydrogen core fusion, horizontal-branch helium core fusion, and AGB hydrogen/helium shell fusion. Cross-sections have independent scales; they are not a size comparison or an evolutionary track. |
| `eclipsing-binary.svg` | A foreground star blocks light; the curve shows one eclipse, not a complete orbital cycle. |
| `ellipsoidal-variable.svg` | A tidally distorted star presents different areas without an eclipse. |
| `accreting-binary.svg` | One possible mass-transfer geometry with an accretion disk. The compact object’s identity depends on the class; this is not a universal binary geometry. |
| `pulsating-star.svg` | Radial expansion/contraction and a separate illustrative brightness curve. Their placement does not imply a phase relation; nonradial variables need other geometries. |
| `rotating-star.svg` | Uneven surface patches change the visible brightness as a star rotates. Darker patches are a representative example; chemical patches can also affect the spectrum and brightness. |
| `young-star.svg` | A disk-bearing young star with inward gas flow; disks are not required for every young-star label. |
| `emission-lines.svg` | Continuum dips and peaks distinguish absorption and emission. |

Definitions and class names follow the linked references in
`src/glossary-subtypes.ts`, including [SIMBAD](https://simbad.cds.unistra.fr/simbad/otypes),
[AAVSO](https://vsx.aavso.org/index.php?view=about.vartypes),
[NASA](https://science.nasa.gov/universe/stars/types/),
[IPAC](https://www.ipac.caltech.edu/2mass/overview/dwarfs.html), and
[ESO](https://www.eso.org/public/ireland/news/eso0133/).
